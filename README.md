# 质量体系管理（有棵树版）

有棵树针织贴身衣物行业专属质量管理体系 Skill，基于 ISO9001:2015 框架（YKS QMS Knitwear ISO9001）

## 项目解决什么问题

针织贴身衣物（文胸/保暖/家居服/塑身/袜子）的质量体系文件审核、条款解读、内审/外审应对依赖人工翻标准；质检数据（仓检合格率/退货率/负评率）与月会报告分散。本技能把体系要求、质量工具、行业标准沉淀为可执行路径。

## 主要功能

| 能力 | 说明 |
|------|------|
| 体系文件审核 | 高频场景一：按 ISO9001 条款审核体系文件的完整流程 |
| 条款解读 | ISO9001:2015 条款库 + IATF16949 对照（references/iso9001_clauses、iatf16949_yks、ISO9001_IATF16949知识库） |
| 内审/外审 | 内审准备、外审应对、审核检查清单（references/audit_checklist、audit_response） |
| 月会前风险研判 | 高频场景三：仓检合格率/退货率/负评率/覆盖率等指标研判（references/monthly_report） |
| 质量工具 | 8D / FMEA / PDCA 指导（references/quality_tools） |
| 行业标准 | 针织贴身衣物行业标准（GB/T 8878、FZ/T 73022 等）、包材 GB 18401 安全类别判定、包材质量整改规范 |
| 产品知识库 | 有棵树自营/联营双轨管控模式与产品库（references/yks_products） |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 无第三方依赖

## 使用方法

触发场景：质量月会/周报、ISO9001、内审/外审、文件审核、8D/FMEA、仓检合格率/退货率/负评率/覆盖率、包材整改、供应商质量异常、针织贴身衣物质检。

## 输入输出示例

**输入：** 审这份体系文件是否符合 ISO9001
**输出：** 按审核流程输出的条款对照问题清单

**输入：** 本月仓检合格率下滑，帮我做月会前研判
**输出：** 指标异常点 + 风险研判 + 8D 工具建议
