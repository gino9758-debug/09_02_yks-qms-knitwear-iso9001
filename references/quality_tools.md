# 质量工具应用详解

## PDCA循环

适用于款号质量改善循环：Plan（款号风险识别）→ Do（产前会/厂检）→ Check（仓检数据）→ Act（异常处置/供应商整改）

## 8D问题解决

适用于供应商批量质量问题：

| 步骤 | 针织贴身衣物场景输出 |
|------|-------------------|
| D1 团队组建 | 采购+QA+QC+供应商 |
| D2 问题描述 | 款号 + 批次 + 问题类型（面料/做工/标识/包材） |
| D3 临时措施 | 暂停发货/全检拦截 |
| D4 根因分析 | 5Why（例：为何色牢度不合格→染料/工艺/面料选择） |
| D5 永久措施 | 换面料/换工艺/换供应商 |
| D6 实施验证 | 仓检数据验证改善效果 |
| D7 预防措施 | 更新检验规范，更新供应商档案 |
| D8 团队表彰 | 改善案例沉淀入库 |

## FMEA分析（针织贴身衣物）

适用场景：
- **DFMEA（设计）**：新款开发，新款式/新面料引入风险
- **PFMEA（过程）**：工艺变更，工厂换工艺/换设备

高风险项（针织贴身衣物）：

| 风险项 | 说明 |
|--------|------|
| 面料成分虚标 | 纤维含量不符实际 |
| 甲醛/可分解芳香胺超标 | 安全类别A/B类要求最严 |
| 色牢度不合格 | 洗后掉色/沾色 |
| 尺寸偏差 | 尺码不准 |
| 做工不良 | 线头/缝位/弹性不足 |
