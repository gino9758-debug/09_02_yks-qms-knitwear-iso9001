# IATF16949:2016 适配说明

> IATF16949为汽车行业标准，有棵树为针织贴身衣物电商/品牌，**不适用IATF16949直接套用**。但其核心理念可迁移适配：

| IATF16949理念 | 有棵树适配应用 |
|-------------|-------------|
| 顾客特殊要求（CSR） | 平台/消费者特殊质量要求（尺码精准、舒适度、面料手感） |
| APQP先期质量策划 | 产前会质量策划（新款式/新工厂须过产前会） |
| PPAP生产件批准程序 | 首批样检验批准流程 |
| FMEA失效模式分析 | 款号质量风险评估（联营风险评估款） |
| 供应商分级管理 | 供应商A/B/C/D级评定，免检资质管理 |
| 过程审核（VDA6.3） | 关键供应商现场审核 |
