# ISO9001:2015 & IATF16949:2016 专家知识库

## 一、ISO9001:2015 标准框架

### 1.1 标准结构（十大条款）

```
第1章    范围
第2章    规范性引用文件
第3章    术语和定义
第4章    组织环境（4.1 4.2）
第5章    领导作用（5.1 5.2 5.3）
第6章    策划（6.1 6.2 6.3）
第7章    支持（7.1 7.2 7.3 7.4 7.5）
第8章    运行（8.1 8.2 8.3 8.4 8.5 8.6 8.7）
第9章    绩效评价（9.1 9.2 9.3）
第10章   改进（10.1 10.2 10.3）
```

### 1.2 关键术语定义

| 术语 | 定义 |
|------|------|
| **质量** | 客体的一组固有特性满足要求的程度 |
| **质量管理** | 关于质量的管理 |
| **质量管理体系** | 建立质量方针和质量目标并实现这些目标的体系 |
| **最高管理者** | 在最高层指挥和控制组织的一个人或一组人 |
| **过程** | 利用输入实现预期结果的相互关联或相互作用的一组活动 |
| **风险** | 不确定性的影响 |
| **纠正措施** | 为消除已发现的不符合或其他不期望情况的原因所采取的措施 |
| **文件化信息** | 组织需要管理和保持的信息及其载体 |

### 1.3 过程方法要求

**PDCA循环**
- **Plan（计划）**：确定目标、制定计划
- **Do（执行）**：实施计划、执行过程
- **Check（检查）**：监测分析、评估效果
- **Act（处理）**：标准化改进、持续循环

**过程识别步骤**
1. 确定体系范围
2. 识别需要的过程
3. 确定过程顺序和相互作用
4. 确定过程准则和方法
5. 确定过程资源和信息
6. 监视测量过程绩效
7. 改进过程

## 二、IATF16949:2016 标准要点

### 2.1 与ISO9001:2015关系

IATF16949是在ISO9001:2015基础上增加汽车行业特定要求，两者关系：
- ISO9001：通用基础要求
- IATF16949：汽车行业补充要求
- 必须同时满足两者

### 2.2 汽车行业核心新增要求

#### 8.3.2 设计与开发策划
- 多专业团队参与
- 设计与开发阶段划分
- 设计与开发评审、验证、确认

#### 8.4.2 外部供方控制
**顾客指定的外部供方**
- 按8.4.2要求控制
- 顾客批准可能是强制性的

**外部供方绩效监视**
| 指标 | 要求 |
|------|------|
| 供应商PPM | ≤500PPM（行业参考值） |
| 交付及时率 | ≥98% |
| 质量问题关闭率 | 100%（30天内） |

#### 9.1.1 过程绩效监视
**产品审核**
- 至少每12个月一次
- 按产品审核检查表执行
- 覆盖所有产品类别

**过程审核**
- 至少每36个月一次
- 按VDA6.3或同等标准
- 覆盖所有关键过程

#### 10.2.3 产品安全
**新增要求**
- 建立产品安全相关过程
- 识别产品安全相关特性
- 产品安全相关记录保存期限（法规+1年）
- 事故通告流程

### 2.3 核心工具要求

#### APQP产品质量先期策划

| 阶段 | 输入 | 输出 | 关键活动 |
|------|------|------|----------|
| 1 | 顾客 voice | 项目立项书 | 确定范围、多部门团队 |
| 2 | 设计概念 | DFMEA、PDCA | DFMEA设计评审 |
| 3 | 设计验证 | 样件、PPAP提交 | 样件制作、试验 |
| 4 | 产品过程确认 | 试生产、PPAP | 试生产、MSA/Gage R&R |
| 5 | 反馈评定纠正 | 量产、持续改进 | 量产、COPQ监控 |

#### PPAP提交等级

| 等级 | 要求项 | 适用场景 |
|------|--------|----------|
| 等级1 | 仅需提交保证书 | 常规采购 |
| 等级2 | 提交保证书+样品 | 常规PPAP |
| 等级3 | 提交保证书+样品+样品尺寸 | 标准提交 |
| 等级4 | 提交保证书+样品+生产件样品+部分过程文件 | 顾客要求 |
| 等级5 | 全部提交+审核记录 | 最严格标准 |

#### FMEA失效模式与影响分析

**DFMEA（设计FMEA）**
- 分析对象：产品设计
- 启动时机：设计概念阶段
- 责任方：设计工程师

**PFMEA（过程FMEA）**
- 分析对象：制造过程
- 启动时机：过程开发阶段
- 责任方：工艺工程师

**严重度S评分（1-10）**

| 评分 | 影响 | 示例 |
|------|------|------|
| 10 | 无警告的严重危害 | 安全带失效 |
| 9 | 有警告的严重危害 | 发动机突然熄火 |
| 8 | 很高 | 车辆无法运行 |
| 7 | 高 | 空调不制冷 |
| 6 | 中等 | 收音机不工作 |
| 5 | 低 | 仪表灯不亮 |
| 4 | 很低 | 杯架不光滑 |
| 3 | 轻微 | 表面有瑕疵 |
| 2 | 非常轻微 | 标签打印不清晰 |
| 1 | 无影响 | 无 |

**频度O评分（1-10）**

| 评分 | 可能性 | 典型PPM |
|------|--------|---------|
| 10 | 极高（每批发生） | >1000 |
| 9 | 很高（经常发生） | 500-1000 |
| 8 | 高（相对持续） | 200-500 |
| 7 | 中高（经常性） | 100-200 |
| 6 | 中等（偶然） | 50-100 |
| 5 | 低（相当少） | 20-50 |
| 4 | 很低（相对少） | 10-20 |
| 3 | 少（极少） | 2-10 |
| 2 | 极少（接近零） | 0.1-2 |
| 1 | 极少（无记录） | <0.1 |

**探测度D评分（1-10）**

| 评分 | 探测方法 | 能力 |
|------|----------|------|
| 10 | 不能探测 | 无 |
| 9 | 非常少 | 极低 |
| 8 | 很少 | 低 |
| 7 | 少 | 低-中 |
| 6 | 中等 | 中等 |
| 5 | 中上 | 中-高 |
| 4 | 很多 | 高 |
| 3 | 几乎肯定 | 高 |
| 2 | 几乎肯定 | 很高 |
| 1 | 肯定 | 100% |

**RPN = S × O × D**
- RPN > 100：必须采取行动
- RPN 50-100：建议采取行动
- RPN < 50：可接受但需监控

### 2.4 制造过程控制要求

#### 关键过程识别
1. 影响产品安全/法规的过程
2. 影响产品功能的过程
3. 特殊特性标识的过程

#### SPC统计过程控制

**控制图选择**
| 数据类型 | 控制图 | 应用场景 |
|----------|--------|----------|
| 计量型 | X̄-R均值极差图 | 尺寸、重量 |
| 计量型 | X̄-S均值标准差图 | 大批量生产 |
| 计数型 | p/np图 | 不良率 |
| 计数型 | c/u图 | 缺陷数 |

**控制限计算**
- UCL = X̄ + 3σ
- CL = X̄
- LCL = X̄ - 3σ

**判异准则**
1. 1点落在控制限外
2. 连续9点在中心线同一侧
3. 连续6点递增或递减
4. 连续14点交替上下
5. 连续3点中有2点在控制限附近

### 2.5 内审员能力要求

**ISO9001要求**
- 理解质量管理原则
- 了解审核方法
- 具备相关过程知识

**IATF16949额外要求**
- 汽车行业经验
- 过程方法审核能力
- 特定工具知识（APQP/FMEA/SPC/PPAP/MSA）
- 完成IATF认可的培训
- 每三年复训

## 三、质量管理体系文件架构

### 3.1 文件层级

```
┌─────────────────────────────────────────────┐
│  第一层级：质量手册                          │
│  描述体系范围、方针、组织架构、过程框架      │
├─────────────────────────────────────────────┤
│  第二层级：程序文件                          │
│  描述过程方法、职责分配、运作要求            │
├─────────────────────────────────────────────┤
│  第三层级：作业指导书                        │
│  描述具体操作步骤、设备参数、工艺要求        │
├─────────────────────────────────────────────┤
│  第四层级：质量记录                          │
│  证明过程已按要求执行的证据                  │
└─────────────────────────────────────────────┘
```

### 3.2 文件编写要点

**质量手册编写要点**
1. 明确体系范围（产品/场所/适用标准）
2. 描述过程及其相互作用（过程图）
3. 引用程序文件
4. 体现领导作用（方针、目标）
5. 风险思维应用

**程序文件编写要点**
1. 明确目的和范围
2. 规定职责和权限
3. 描述工作流程
4. 引用相关文件
5. 确定记录要求

### 3.3 记录管理

| 记录类型 | 保存期限 | 示例 |
|----------|----------|------|
| 产品记录 | 产品寿命+1年 | 检验报告、试验报告 |
| 体系记录 | 3年或合同期 | 内审记录、管理评审 |
| 不符合项记录 | 3年 | NCR、8D报告 |
| 人员记录 | 在岗期间+1年 | 培训记录、资质证书 |

## 四、审核实施指南

### 4.1 审核计划编制

**年度审核计划要素**
- 审核范围和频次
- 审核方法（体系/过程/产品）
- 审核员安排
- 资源要求

**审核方案策划**
1. 确定审核目标
2. 确定审核范围和准则
3. 选择审核方法
4. 分配资源
5. 监视测量有效性

### 4.2 审核检查表编制

**条款检查表要素**
1. 审核准则（标准条款）
2. 审核证据（查什么）
3. 审核方法（怎么查）
4. 判定标准（合格判定）

**过程审核检查表（VDA6.3）**
```
P1 过程导向（潜在分析）
├── P1.1 过程开发策划
├── P1.2 过程开发结果
├── P1.3 过程放行
├── P1.4 过程能力
└── P1.5 过程监视

P2 过程支持（实际过程）
├── P2.1 过程输入要求
├── P2.2 资源管理
├── P2.3 过程执行
├── P2.4 过程测量分析
└── P2.5 过程输出
```

### 4.3 不符合项报告（NCR）

### 4.4 审核报告编写

**审核报告结构**

5. 审核结论
6. 附件（不符合项清单、检查表等）

## 五、持续改进机制

### 5.1 改进类型

| 类型 | 触发条件 | 实施周期 | 资源投入 |
|------|----------|----------|----------|
| 纠正措施 | 已发生不符合 | 短期 | 中 |
| 预防措施 | 潜在不符合 | 中期 | 中高 |
| 持续改进 | 绩效优化 | 长期 | 高 |

### 5.2 改进工具

**PDCA循环应用**
- 小改进：单次循环
- 项目改进：多轮PDCA
- 体系优化：PDCA嵌套

**DMAIC改进路径**
```
Define（定义）：确定问题、设定目标
     ↓
Measure（测量）：收集数据、测量现状
     ↓
Analyze（分析）：分析原因、识别根因
     ↓
Improve（改进）：制定方案、实施改进
     ↓
Control（控制）：验证效果、标准化
```

### 5.3 质量成本分析

**COQ质量成本分类**

| 类别 | 定义 | 占比参考 |
|------|------|----------|
| 预防成本 | 预防缺陷发生的成本 | 5-10% |
| 鉴定成本 | 评估产品质量的成本 | 10-25% |
| 内部失败成本 | 交付前发现缺陷的成本 | 20-30% |
| 外部失败成本 | 交付后发现缺陷的成本 | 30-40% |

**理想目标**
- 预防成本占比提高
- 失败成本占比降低
- 总质量成本下降

## 七、质量管理统计技术

### 7.1 基础统计概念

**总体与样本**
- 总体：研究对象的全部个体
- 样本：从总体中抽取的部分个体
- 样本量n：样本包含的个体数

**常用统计量**
- 均值（X̄）：反映数据集中趋势
- 标准差（σ）：反映数据离散程度
- 不良率（p）：不合格品数/总检验数

**正态分布特征**
- 68.26%数据落在±1σ
- 95.45%数据落在±2σ
- 99.73%数据落在±3σ

### 7.2 过程能力分析

**Cp/ Cpk计算**
```
Cp = (USL - LSL) / 6σ
Cpk = min[(USL - μ) / 3σ, (μ - LSL) / 3σ]
```

**能力等级判定**

| Cpk范围 | 能力等级 | 判定 |
|---------|----------|------|
| Cpk ≥ 2.0 | 能力过剩 | 降低要求 |
| 1.67 ≤ Cpk < 2.0 | 能力充分 | 理想状态 |
| 1.33 ≤ Cpk < 1.67 | 能力尚可 | 关注改进 |
| 1.0 ≤ Cpk < 1.33 | 能力不足 | 需要改进 |
| Cpk < 1.0 | 能力严重不足 | 紧急改进 |

### 7.3 测量系统分析（MSA）

**Gage R&R判定**
```
%R&R = Gage R&R / 总变异 × 100%
```

| %R&R | 判定 |
|------|------|
| < 10% | 测量系统可接受 |
| 10-30% | 勉强接受，需改进 |
| > 30% | 不可接受，需改进 |

| FZ/T 80002-2016 | 服装标志、包装、运输和贮存 | 标识规范 |

### 9.3 GB 18401 安全类别判定

| 类别 | 适用年龄/场景 | 甲醛 | 可分解芳香胺 | pH值 | 有棵树适用场景 |
|------|--------------|------|------------|------|--------------|
| A类（婴幼儿） | 36个月及以下 | ≤20mg/kg | 禁用 | 4.0~7.5 | 婴儿类贴身（如有涉及） |
| B类（直接接触皮肤） | 成人/儿童贴身 | ≤75mg/kg | 禁用 | 4.0~8.5 | 内裤、文胸、家居服、塑身、袜子等**核心品类** |
| C类（非直接接触皮肤） | 外穿类 | ≤300mg/kg | 禁用 | 4.0~9.0 | 外穿外套等 |

### 9.4 标准检索路径

当用户询问某产品的标准依据时：
1. 先判断品类（内裤/文胸/保暖/塑身/袜子等）
2. 再查对应产品标准（见上方表格）
3. 结合 GB 18401 安全类别判定（A/B/C类）
4. 如有企业标准则叠加 Q/YKS 要求
5. 输出标准编号、标准名称、关键指标、判定结论

### 9.5 有棵树质检关键指标判定

| 检测项目 | B类要求 | 针织贴身衣物常见不合格原因 |
|---------|---------|----------------------|
| 耐水色牢度 | ≥3级 | 深色面料首次水洗掉色 |
| 耐汗渍色牢度 | ≥3级 | 汗液环境下染料迁移 |
| 耐干摩擦色牢度 | ≥3级 | 摩擦接触区域掉色（腰头/橡筋） |

| pH值 | 4.0~8.5 | 面料酸碱处理不当 |
| 甲醛 | ≤75mg/kg（B类） | 廉价面料定型处理残留 |
| 可分解芳香胺 | 禁用 | 偶氮染料（禁用染料） |
