# 内审专项检查表

## 专项检查项

| 检查领域 | 检查要点 |
|---------|---------|
| 仓检执行 | QI是否按SOP执行，黄标/红标隔离是否合规 |
| 免检资质 | 免检供应商是否仍在有效期，是否触发预警未取消 |
| 产前会覆盖 | 自营新开款是否100%召开产前会，留存记录 |
| 风险评估覆盖 | 联营风险评估款是否100%完成查货 |
| 包材验收 | 包材是否符合GB 18401安全类别（A/B/C类） |
| 罚款落实 | 应罚/实罚是否按月拆分，跟进进度 |

## 不符合项判定标准

| 严重程度 | 判定标准 | 处理要求 |
|----------|----------|---------|
| **严重不符合** | 系统性失效（如免检资质大面积失控） | 暂停认证/暂停注册 |
| **主要不符合** | 局部失效/个别严重不符合 | 限期整改+跟踪审核 |
| **次要不符合** | 偶发/个别的遗漏 | 下次审核确认 |

## 文件审核清单

```
├── 格式合规性
│   ├── 文件编号格式
│   ├── 版本号管理
│   ├── 页眉页脚规范
│   └── 审批签字齐全
├── 内容合规性
│   ├── 符合标准条款（ISO9001 + 纺织行业标准）
│   ├── 职责权限清晰
│   ├── 引用文件有效
│   └── 记录表格适用
└── 时效性检查
    ├── 发布日期有效
    ├── 审核周期合规
    └── 过期文件清理
```
