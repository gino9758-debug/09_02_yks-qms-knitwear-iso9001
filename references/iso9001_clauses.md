# ISO9001:2015 核心条款速查（针织贴身衣物行业适配）

## 十大条款速查

| 条款 | 名称 | 针织贴身衣物行业关键要求 |
|------|------|----------------------|
| 4.1 | 组织环境 | 确定品类范围（文胸/保暖/家居服等）、供应链特性 |
| 4.2 | 理解相关方需求 | 顾客（消费者）、平台电商、联营商的质量期望 |
| 5.1 | 领导作用 | 质量方针覆盖自营+联营双轨管控 |
| 5.2 | 质量方针 | 方针内涵、目标（仓检合格率≥98%等） |
| 6.1 | 风险与机遇 | 供应商质量风险、季节性产品风险、平台抽检风险 |
| 6.2 | 质量目标 | 仓检合格率、退货率、负评率、覆盖率等量化目标 |
| 7.1 | 资源提供 | 质检设备（拉力机、色牢度仪）、验货人员配置 |
| 7.2 | 能力与意识 | QC/QA/QI岗位培训、持证上岗 |
| 8.1 | 运营策划 | 产前会策划、风险评估款覆盖 |
| 10.2 | 不符合与纠正 | 质量异常处置流程、8D改进 |
