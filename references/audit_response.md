# 外审应对指南

## 审核应对话术原则

| 问题类型 | 应对策略 | 禁忌 |
|----------|----------|------|
| 开放式问题 | 用数据/事实回答（如：仓检合格率95.6%，目标98%） | 回避/编造 |
| 追溯性问题 | 提供完整记录链（批次检验记录/异常处置记录） | 断档/涂改 |
| 异常追问 | 承认不足+改进计划（整改进度/完成时限） | 辩解/推脱 |
| 场景观察 | 边做边说/过程可视化（验货现场/仓库） | 停顿/紧张 |

## 常见审核必问题清单

审核中极大概率被问到的问题，审核前务必准备完整答案和数据：

1. **仓检合格率目标是多少？实际达成如何？**
2. **联营供应商退货率/负评率超标的处置流程是什么？**
3. **免检资质供应商如何管理，出现预警如何处理？**
4. **产前会覆盖率如何追踪？**
5. **包材安全类别（GB 18401）如何确保合规？**

## 回答原则

- **数据优先**：所有回答必须有具体数字支撑
- **闭环意识**：每个问题均应展示"发现→分析→处置→验证"闭环
- **记录意识**：审核前确认所有记录可调取、无断档
