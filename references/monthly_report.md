# 质量月会汇报标准结构

> 适用于自营+联营双轨汇报场景。

## 四板块标准结构

### 板块1：数据异常需特别关注
- 各品类退货率、负评率、合格率 TOP 异常款号/工厂
- **必须包含**：具体款号、工厂名、指标数值、风险等级
- **禁止写**：「需重点关注」「整体可控」等空泛结论

### 板块2：业务卡点需关注
- 包材质量异常（款号+工厂+问题+整改+截止）
- 供应商资质（免检资质管理滞后说明）
- 罚款落实情况（每月应罚/实罚/执行进度）
- 产前会覆盖率考核闭环情况

### 板块3：业务管控与汇报需增补
- 异常闭环追踪（超标指标溯源）
- 质量预警看板（新增风险点）
- 渠道深挖（退货/负评到渠道维度）

### 板块4：管控风险/建议决策事项
- 推动当场拍板的结论清单
- 每条结论明确：背景 + 选项 + 建议

## 月会前风险研判流程

**触发时机**：月报出来后、月会开始前。

**分析维度**：
1. **数据异常** → 月报数据 vs 上月/同期，标红超标项
2. **业务卡点** → 包材、供应商资质、罚款落实、结构性卡点
3. **管控增补** → 异常闭环缺失、预警看板缺项、渠道深挖必要性
4. **风险决策清单** → 结论 → 推送执行者执行落地

**操作流程**：
1. 读取多维表格最新数据
2. 读取月报文档（飞书）
3. 对比指标阈值，标红超标项
4. 按四板块结构输出研判报告
5. 将执行项推送给执行者（如质量管理负责人）执行落地

## 关键指标阈值

| 指标 | 目标值 | 预警值 | 说明 |
|------|--------|--------|------|
| 仓检合格率 | ≥98% | <98% | 触发供应商管控升级 |
| 退货率 | ≤同类目均值 | >均值20%暂停发货 | 质量原因退货 |
| 负评率 | ≤同类目均值 | >均值20%专项质检 | 差评率 |
| 覆盖率（自营+联营） | 100% | <100% | 记录未完成款数 |
| 质量异常审批率 | ≤0.5% | >0.5% | 超标须溯源 |
| QA批样数量 | 100%产前会覆盖 | 缺失记录 | 自营新开款 |
| 产前会覆盖率 | 100% | <100% | 自营/联营风险评估款 |
| 风险评估覆盖率 | 100% | <100% | 联营风险评估款 |
